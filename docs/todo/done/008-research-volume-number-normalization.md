# 巻数表記の正規化規則を調査

## 状態

完了。

実データ調査に加え、今回の共通モデル変更で公開API仕様、MADB変換規則、実装、テストまで
[TODO012](012-redesign-common-book-model.md)として完了した。

## 完了した内容

- 取得元の巻数表記を `Sources[0].Values.Volume` に変更せず保持する
- 正規化結果を `Normalized.Volume` に分離する
- 整数化できる巻数を `Volume.Number *int` と10進数の `Volume.Label` で返す
- 上中下巻、前後編、別巻、外伝、番外編、小数巻は `Label` だけで返す
- 同じ巻数を `/` または `／` で併記した表記は、両側が同じ結果になる場合だけ
  正規化する
- 許可した構文に完全一致しない値や競合する併記は推測で正規化しない
- 正規化できない値をエラーにせず、取得元の表記だけを残す
- 並べ替え専用のIndexは公開モデルへ追加しない

## 検証済みの境界

- 数値巻、0巻、全角数字、許可した接頭辞・接尾辞
- 上中下巻、前後編、別巻、外伝、番外編
- 小数巻
- 同値と競合値を含む併記
- 空値と解析対象外の表記
- 元表記を保持したまま正規化値を返すJSON構造

## 対象外として確定した内容

- タイトルからの巻数抽出
- 漢数字、範囲、枝番、合本を推測で数値化する処理
- 巻数による検索結果のソートとページング
- 複数取得元を統合したシリーズ全体の巻順保証
- 全文字列項目への一律のUnicode正規化
