# MADBタイトル検索のCLIデモを追加

## 背景

- READMEには `manken` と `madb` の最小利用例があるが、任意のタイトルを指定して
  実行できるサンプルプログラムはない
- 利用者がMADBの実サービスを検索し、取得結果やエラーを手元で確認できる
  デバッグ手段が必要である

## 目的

- `manken` と `madb` をimportしてタイトル検索を実行するCLIデモを追加する
- 利用者が任意の検索条件で実サービスの結果を確認できるようにする
- ライブラリ利用時の入力、検索、結果出力、エラー処理を1ファイルで確認できる
  例を提供する

## 非目的

- 汎用的なCLIアプリケーションの実装
- HTML画面やローカルWebサーバーの実装
- `examples` 配下のサブディレクトリ化
- 外部CLIフレームワークの導入
- キャッシュ、自動リトライ、アクセス間隔の制御
- ISBN、著者名、シリーズ名による検索
- デモ専用の自動テストファイルの追加

## 前提・制約

- 実装は `examples/demo-madb.go` の1ファイルで完結させる
- Go標準ライブラリ、`github.com/eamat-dot/manken`、
  `github.com/eamat-dot/manken/madb` だけを使用する
- 検索処理は公開APIだけを使用し、ライブラリ本体の公開APIを変更しない
- MADBへの接続には `madb.NewClient(nil)` の既定設定を使用する
- JSON以外の案内やエラーを標準出力へ混在させない

## CLI仕様

### 実行例

```text
go run ./examples/demo-madb.go -title "動物のおしゃべり" -limit 5
```

### 入力

- `-title` で検索するタイトルを指定する
- `-title` は必須とし、未指定または空白だけの場合は使い方を示して終了する
- `-limit` で取得件数を指定する
- `-limit` の既定値は0とし、実際の既定件数はライブラリへ委ねる
- `-cursor` で前回の結果に含まれるカーソルを指定できるようにする
- 検索全体に60秒のタイムアウトを設定する

### 出力

- 成功時は `manken.SearchBooksResult` をインデント付きJSONとして標準出力へ出す
- 0件の場合も成功として、空の `books` を含むJSONを出す
- `next_cursor` を省略せず出力し、次ページの確認に再利用できるようにする
- 入力エラー、検索エラー、JSON出力エラーは標準エラー出力へ出す
- 成功時は終了コード0、失敗時は0以外で終了する

## リスク・懸念

- MADBのサービス状態やデータ更新により、同じ検索でも結果や応答時間が変わる
- 実サービス確認はネットワーク接続を必要とし、通常の自動テストとは分離して
  実行する必要がある
- カーソルはタイトルと取得件数に対応するため、次ページでも同じ `-title` と
  `-limit` を指定する必要がある
