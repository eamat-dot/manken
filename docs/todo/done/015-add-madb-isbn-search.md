# MADBにISBN検索を追加

## 状態

2026年8月1日完了。

## 背景

- `schema:isbn` は取得済みだが、検索条件には使用できない
- MADBにはISBN-10とISBN-13の両方、片方だけ、欠落、不正な付記付き値が存在し得る

## 目的

- ISBN-10またはISBN-13から漫画単行本を検索できるようにする
- 入力ISBNの表記を検証し、同じ本のISBN-10とISBN-13の差を吸収する

## 根拠

- [`../../research/014-madb-search-conditions.md`](../../research/014-madb-search-conditions.md)
- [`../../pkg/madb/spec.md`](../../pkg/madb/spec.md)

## 非目的

- JAN、商品番号、MADB IDによる検索
- 不正なISBN値の推測修正
- 同じISBNを持つ複数リソースの統合

## 前提・制約

- `SearchBooksRequest` へ `ISBN string` を追加する
- `Title` または `ISBN` の少なくとも一方を必須にし、両方の指定はAND条件にする
- 014完了後に実施し、後続TODOで正条件の種類を追加できる検証構造にする
- ISBN検索でもURIキーセットページングを使用する

## 処理方針

1. 入力からASCIIハイフンとUnicode空白を除き、末尾 `x` を `X` にする
2. ISBN-10またはISBN-13のチェックディジットを検証する
3. ISBN-10からISBN-13を生成し、`978`で始まるISBN-13からISBN-10を生成する
4. 入力値と生成できた対応値を重複除去して `VALUES ?searchISBN` へ指定する
5. `?resource schema:isbn ?searchISBN` を他の正条件とAND結合する

## 実装結果

- ISBN-10と978 ISBN-13を相互変換し、979 ISBN-13は変換せず検索する
- 正規化済みタイトルとISBN候補をカーソル形式バージョン2へ結び付けた
- `4088466361` はチェックディジットが不正だったため、対応する正しいISBN-10を
  `4088466365` として調査記録と実サービス検証条件を訂正した
- 実サービスでISBN-10とISBN-13の両方から `M190399` を取得し、タイトルとの
  AND検索とデモCLIの `-isbn` も確認した
