# MADBにフリーワード検索を追加

## 状態

2026年8月1日完了。

## 背景

- 現行APIはタイトルだけを検索対象にする
- MADBの公式詳細検索はフリーワードと個別項目を提供する
- 公開SPARQLではフィールド省略と `field "*"` が失敗し、対象項目の明示が必要だった
- 明示した複数フィールドでは、タイトル、creator、版表示をまたぐAND検索が成功した

## 目的

- 漫画単行本リソース上の主要な文字列項目を横断して検索できるようにする
- タイトル、著者名、版表示、判型などの個別条件をAND結合して絞り込めるようにする

## 根拠

- [`../../research/014-madb-search-conditions.md`](../../research/014-madb-search-conditions.md)

## 非目的

- MADBの全プロパティを無条件に検索すること
- Agent参照だけに存在する著者名をフリーワードだけで完全に検索すること
- 検索結果の関連度順ソート
- 検索対象フィールドを利用者が任意指定するAPI

## 前提・制約

- `SearchBooksRequest` へ `FreeText string` を追加する
- 014から016の検索条件とカーソル拡張後に実施する
- Agent参照だけの著者を漏れなく探す場合は `Author` を使用する
- 検索対象フィールドはMADB固有仕様に置き、共通モデルの意味と混同しない

## 対象フィールド

- `schema:name`
- `schema:alternativeHeadline`
- `ma:seriesName`
- `schema:volumeNumber`
- `schema:creator`
- `schema:publisher`
- `schema:brand`
- `schema:version`
- `schema:isbn`
- `schema:description`
- `schema:keywords`
- `schema:size`

## 処理方針

1. フリーワードをUnicode空白で分割する
2. 各語を安全な引用句へ変換し、`AND` で結ぶ
3. `query_string` の `field` として対象フィールドを明示する
4. タイトル、ISBN、著者名などの正条件とAND結合する
5. 判型や版を個別の公開フィールドへ増やさず、初期実装では `FreeText` で扱う

- `schema:size` は寸法文字列であり、一般的な判型名が必ず存在するわけではない

## 実装結果

- `SearchBooksRequest.FreeText` とデモCLIの `-free-text` を追加した
- 漫画単行本リソース上の12フィールドを明示した1つの `query_string` で検索し、
  タイトル、ISBN、著者名の専用条件とはAND結合した
- Unicode空白の正規化、全文検索とSPARQLの二段階エスケープ、カーソル条件への
  結び付けを既存条件と同じ規則で実装した
- フリーワードの検索語数にはライブラリ独自の上限を設けず、Contextまたは
  HTTPクライアントのタイムアウトで制御する仕様とした
- 実サービスで1語は約1.15秒、2語は約0.53秒、3語は約0.06秒で完了した
- タイトル、副題、シリーズ名、creator、出版社、レーベル、版表示、判型の
  代表検索は最長約6.7秒で完了した
