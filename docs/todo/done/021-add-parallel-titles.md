# 共通書籍モデルに並列タイトルを追加

状態: 完了（2026年8月3日）

## 背景

- 取得元が日本語題と別言語題を1つのタイトル文字列として返す場合がある
- 現在の `NormalizedBook` は主タイトルとサブタイトルを持つが、同じ内容を
  別言語で表す並列タイトルを保持できない
- 並列タイトルを捨てて主タイトルだけを残すと、取得元が提供した情報を
  正規化結果から確認できない
- 別題、略題、表紙題まで含む代替タイトルとは分けて扱う必要がある

## 目的

- `NormalizedBook` に、主タイトルと同じ内容を別言語で表す並列タイトルを追加する
- 取得元の完全なタイトル文字列を変更せず `Sources` に残したまま、
  安全に分解できた値だけを共通モデルへ設定できるようにする
- openBDのタイトル変換で英語題を削除せず保持できるようにする

## 非目的

- 代替タイトル、略題、表紙題、原題を一括して共通化すること
- 翻訳タイトルを生成すること
- 取得元にないタイトルを補完すること
- openBD固有のタイトル分解規則の実装
- 巻数正規化の実装

## 前提・制約

- 共通名は `ParallelTitles` とする
- 並列タイトルは複数件を順序付きで保持する
- 取得元が返した完全なタイトル文字列は `SourceBookValues.Titles` に変更せず残す
- 分解できないタイトルは全体を `Normalized.Title` に設定し、情報を削除しない
- 要約、翻訳、推測による追加、意味を変える置換は行わない
- Raw response全体は既存どおり専用メソッドで返し、`Book` へ埋め込まない

## 公開API仕様

```go
type NormalizedBook struct {
	Title          string   `json:"title,omitempty"`
	ParallelTitles []string `json:"parallel_titles,omitempty"`
	// その他の既存フィールド
}
```

- `ParallelTitles` は同じ内容を別の言語または文字体系で表したタイトルとする
- 取得元が示した順序を維持する
- 欠落時はJSONから省略する
- 取得元で並列タイトルと確認できない別題は設定しない
- 区切り文字など、構造を表す文字は正規化値に含めなくてよい
