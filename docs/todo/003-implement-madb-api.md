# MADBタイトル検索APIを実装

## 背景

- テンプレート移行とMADB仕様調査の完了後、確定した `manken` APIを実装する必要がある
- 外部サービス固有の形式を公開APIへ露出させず、複数のGoプロジェクトと将来のMCPサーバーから利用できる形にする

## 目的

- `docs/spec.md` と `docs/pkg/madb/spec.md` で確定した共通モデルと
  MADBタイトル検索APIを実装する
- 外部通信を行わない単体テストと、明示的な実サービス確認を整備する
- 別のGoモジュールからimportできる状態にする

## 着手条件

- [ ] `001-migrate-template.md` が完了している
- [ ] `002-research-madb-api.md` が完了している
- [ ] `docs/spec.md` の共通APIに必要な未確定事項が解消されている
- [ ] `docs/pkg/madb/spec.md` の初期実装に必要な未確定事項が解消されている
- [ ] 実装対象の公開APIについて利用者の承認を得ている

## 非目的

- テンプレートファイルの移行
- MADB仕様の追加調査
- ISBN検索、著者名検索、シリーズ検索
- MADB以外のデータ取得元への対応
- キャッシュ、自動リトライ、レート制限
- CLIとMCPサーバーの実装
- GitHub Releaseとバージョンタグの作成
