# 楽天Books・Koboコミックジャンル調査

## 1. 目的

楽天Booksと楽天Koboのタイトル検索を漫画単行本へ限定するため、一般コミック、
BLコミック、TLコミックの検索に使用するジャンルIDを確認する。

この文書は2026-07-31時点の公式仕様と実APIの確認結果であり、確定仕様ではない。
ジャンルIDと件数は将来変更される可能性がある。

## 2. 公式仕様

参照した公式ページ:

- 楽天ブックス書籍検索API:
  https://webservice.rakuten.co.jp/documentation/books-book-search
- 楽天ブックスジャンル検索API:
  https://webservice.rakuten.co.jp/documentation/books-genre-search
- 楽天Kobo電子書籍検索API:
  https://webservice.rakuten.co.jp/documentation/kobo-ebook-search
- 楽天Koboジャンル検索API:
  https://webservice.rakuten.co.jp/documentation/kobo-genre-search

楽天ブックス書籍検索APIは、`booksGenreId=001` の「本」に属するジャンルを
検索条件に指定できる。`title` は半角空白で区切った複数キーワードを指定できる。

楽天Kobo電子書籍検索APIは、`koboGenreId=101` の「電子書籍」に属するジャンルを
検索条件に指定できる。複数キーワードに対して、次の条件を指定できる。

- `orFlag=0`: AND検索
- `orFlag=1`: OR検索
- `field=0`: 広い検索範囲
- `field=1`: 限定した検索範囲
- `NGKeyword`: 検索結果から除外するキーワード

ジャンル検索APIはジャンル名と親子関係の調査に使う。通常のタイトル検索では、
検索レスポンスにジャンルIDが含まれるため、ジャンル名を取得する必要はない。

## 3. 検索に使用するジャンルID

### 3.1 楽天Books

確認した階層は次のとおり。

```text
000
└── 001 本
    ├── 001001 漫画（コミック）
    │   ├── 001001001 少年
    │   ├── 001001002 少女
    │   ├── 001001003 青年
    │   ├── 001001004 レディース
    │   ├── 001001006 文庫
    │   └── 001001012 その他
    ├── 001021 ボーイズラブ（BL）
    │   ├── 001021001 小説
    │   ├── 001021002 コミック
    │   └── 001021003 その他
    └── 001029 ティーンズラブ（TL）
        ├── 001029001 小説
        └── 001029002 コミック
```

検索用IDの候補:

| 検索区分 | ID | 理由 |
| --- | --- | --- |
| 一般コミック | `001001` | 少年、少女、青年、レディースなどを1回で検索できる |
| BLコミック | `001021002` | BL小説を含めずコミックだけを検索できる |
| TLコミック | `001029002` | TL小説を含めずコミックだけを検索できる |

### 3.2 楽天Kobo

確認した階層は次のとおり。

```text
101 電子書籍
├── 101904 漫画（コミック）
│   ├── 101904001 少年
│   ├── 101904002 青年
│   ├── 101904011 少女
│   ├── 101904012 レディース
│   └── 101904090 その他
└── 101940 BL・TL
    ├── 101940001 BL 小説
    ├── 101940002 BL コミック
    ├── 101940010 TL 小説
    ├── 101940011 TL コミック
    └── 101940090 その他
```

検索用IDの候補:

| 検索区分 | ID | 理由 |
| --- | --- | --- |
| 一般コミック | `101904` | 少年、青年、少女、レディースなどを1回で検索できる |
| BLコミック | `101940002` | BL小説を含めずコミックだけを検索できる |
| TLコミック | `101940011` | TL小説を含めずコミックだけを検索できる |

楽天BooksとKoboはジャンル体系とIDが異なるため、同じ定数や対応表を共有しない。

## 4. 親ジャンル指定の確認

検索語を指定せず、各候補IDから3件だけ取得した。件数は2026-07-31時点の
一時的な値であり、検索結果の規模を示す参考値に限る。

| API | 指定ID | 総件数 | 返却されたジャンルIDの例 |
| --- | --- | ---: | --- |
| 楽天Books | `001001` | 108,922 | `001001003044` |
| 楽天Books | `001021002` | 8,365 | `001021002016/001001002015` |
| 楽天Books | `001029002` | 2,035 | `001029002015` |
| Kobo | `101904` | 717,370 | `101904090` |
| Kobo | `101940002` | 93,407 | `101940002/101904011025` |
| Kobo | `101940011` | 10,859 | `101940011008/101940001` |

一般コミックの親IDを指定すると、その子孫ジャンルの商品が返った。一般検索で
少年、少女、青年などを個別に検索する必要はない。

一方、1商品が複数ジャンルへ所属する場合は、最下位ジャンルIDが `/` 区切りで
返る。BL・TL商品に一般コミック側のIDが併記される実例があった。

一般、BL、TLの指定は、検索時に使用するジャンルを1つに決め、複数カテゴリへの
フォールバックを避けるためのものである。作品を相互排他的に分類することは
目的としない。一般コミック検索でBL・TLのジャンルIDが併記された商品が返っても、
そのことだけを理由に除外しない。

## 5. 区分ごとの検索条件

検索1回につき1区分だけを指定する。一般、BL、TLを毎回すべて検索せず、
利用者がBLまたはTLを明示した場合だけ対応するジャンルIDを使用する。
指定した区分以外のジャンルIDが併記されていても、NOT条件には使わない。

### 5.1 一般コミック

楽天Books:

```text
booksGenreId=001001
```

Kobo:

```text
koboGenreId=101904
```

BL・TLのジャンルIDが併記された商品も除外しない。

### 5.2 BLコミック

楽天Books:

```text
booksGenreId=001021002
```

Kobo:

```text
koboGenreId=101940002
```

一般コミック側のジャンルIDが併記されていても除外しない。

### 5.3 TLコミック

楽天Books:

```text
booksGenreId=001029002
```

Kobo:

```text
koboGenreId=101940011
```

一般コミック側のジャンルIDが併記されていても除外しない。

返却されたジャンルIDは書誌情報または診断情報として保持できるが、区分間の
排他的なフィルターには使わない。

## 6. タイトル検索の実レスポンス

一般コミック区分で `ふつつかな悪女ではございますが` を検索した。

| API | 指定ジャンル | 総件数 | 確認結果 |
| --- | --- | ---: | --- |
| 楽天Books | `001001` | 14 | 返却された10件はコミックで、各商品に13桁ISBNがあった |
| Kobo | `101904` | 12 | 返却された10件は同作の電子コミックだった |

同名の原作小説は混入しなかった。カテゴリ指定は、コミカライズ作品の
原作小説を避ける条件として有効だった。

楽天Booksで取得したISBNは、形式とチェックディジットを検証して重複除去した後、
openBDへまとめて問い合わせる。openBDに収録されていないISBNについては、
楽天Booksの情報を部分的な書誌情報として利用する余地を残す。

## 7. Koboの除外キーワード

`鉄鍋のジャン` を一般コミック区分で検索し、`NGKeyword` の有無を比較した。

指定した除外語:

```text
分冊 話売り 単話版 連載版 巻セット 期間限定 無料お試し 試し読み
無料版 立ち読み 試読版
```

| 条件 | 総件数 | 先頭30件の除外語該当タイトル |
| --- | ---: | ---: |
| `NGKeyword`なし | 526 | 5 |
| `NGKeyword`あり | 33 | 0 |

`NGKeyword` は候補数と分冊版などの混入を大きく減らした。ただし、API側の
除外だけを共通契約の根拠にせず、取得後にも同じ除外条件を適用する。

Koboの検索条件は次を候補とする。

```text
title=<利用者の検索語>
keyword=<利用者の検索語>
koboGenreId=<選択した区分のID>
field=1
orFlag=0
NGKeyword=<取得元用の除外語>
```

検索語を構成する語はAND検索とし、取得後にも表記をそろえたタイトルへ
すべての必須語が含まれることを確認する。あいまい一致やOR検索は初期対象にしない。

楽天ブックス書籍検索APIには、Koboと同じ `NGKeyword`、`field`、`orFlag` は
ない。タイトルとジャンルで候補を取得し、単巻ではない商品やタイトル不一致を
取得後に除外する。

## 8. 実装時の定数

個々のIDを取得元パッケージ内の非公開定数にし、検索時にジャンル検索APIを
呼び出さない。

```go
const (
	rakutenBooksGenreGeneralComic = "001001"
	rakutenBooksGenreBLComic      = "001021002"
	rakutenBooksGenreTLComic      = "001029002"
)

const (
	rakutenKoboGenreGeneralComic = "101904"
	rakutenKoboGenreBLComic      = "101940002"
	rakutenKoboGenreTLComic      = "101940011"
)
```

定数のコメントにはジャンル名と確認日を残す。ジャンル名が必要な場合も、
この6件だけをローカルの対応表で管理する。通常検索の結果ごとにジャンル検索APIを
呼び出さない。

## 9. アダルトコミック

今回確認した一般、BL、TLの上位階層には、独立したアダルトコミック検索区分は
見つからなかった。末端ジャンルを含む全階層の調査は行っていないため、
楽天のジャンル情報だけで成人向け作品を完全に識別または除外できるとは
判断しない。

アダルトコミックを明示的に検索する機能は初期実装の対象外とする。一方、
一般、BL、TLの検索結果へ成人向け作品が混在しても、成人向けであることを
判定して除外する処理は設けない。将来、明示的な検索区分が必要になった場合は、
年齢制限の判定方法と取得元の利用条件を別の調査対象にする。

## 10. 調査時点の判断

- 一般、BL、TLは利用者が1区分を指定し、1回の検索で1ジャンルIDを使う。
- 未指定時は一般コミックとし、BLまたはTLへ自動フォールバックしない。
- 楽天BooksとKoboのジャンルIDは取得元別の非公開定数として保持する。
- 通常検索ではジャンル検索APIを呼び出さない。
- 区分指定は検索経路を決めるために使い、ジャンル併記作品の除外には使わない。
- 検索語はAND条件とし、取得後にもすべての必須語を確認する。
- Koboでは `field=1`、`orFlag=0`、`NGKeyword` を使い、取得後も除外する。
- 紙書籍は有効なISBN-13を抽出し、openBDで詳細を一括取得する。
- アダルトコミックの明示検索は初期対象外とし、通常結果からの除外もしない。
